# 城市街区视觉样板

打开 `Scenes/CityBlockPreview.unity` 即可看到完整静止街区。Play 后飞机会轻微浮动，城市保持静止。

## 本版完成

- 64×64 米街区，8×8 米拼接单元。39 块道路连通，21 栋建筑和一个小公园。
- 六种独立建筑预制体：三层公寓、五层办公楼、两层街角商铺、四层公寓、两层住宅、三层商住楼。
- 直路、弯路、T 字路、十字路四种独立预制体。道路连接口一致，总宽 8 米，车行道 6 米。
- 两种树形、长椅、花池、绿篱和路灯预制体。地面、建筑和道具使用不同资源，便于独立替换。
- 固定 45° 俯角 / 45° 水平朝向的正交镜头、真实三维阴影、低饱和城市和红白飞机。

视觉依据是仓库 `Art/CityKit-v1/ART-DIRECTION.md` 及两张参考板。参考板没有透明背景且没有精确拼接信息，所以本场景使用程序制作的简单三维几何和像素采样贴图，没有直接裁切或贴上参考板。精细美术、叶片、外楼梯等细节仍待后续制作。

## 修改配置

仓库 `outputs/01a07d7e-02e3-7892-acf1-37a31ca56b3a/buildings.xlsx` 新增 `city_buildings` 工作表。id 7–12 为数字字符串；原 `buildings` 工作表继续控制早期飞行原型。

1. 修改 `city_buildings` 工作表，导出 CSV UTF-8，覆盖本目录的 `Data/city_buildings.csv`。
2. 回到 Unity，等待导入。
3. 选中场景里的 `City block layout`，在 CityBlockLayout 组件菜单执行 **Rebuild static block**。
4. 可用 `OnAir > Validate city block` 检查。

这版按照模型实际尺寸摆放，`min_scale` 和 `max_scale` 必须为 1。楼层高度、占地和外观在预制体中调整。不会静默忽略缩放配置。

生成时先筛选城市 / 天气 / 时段，再筛选当前地块允许的楼层与尺寸，然后按权重选取。同种建筑不连续选超过两次；无候选时放花池，不突破地块规则。

## 替换建筑

在 `Data/CityBuildingCatalog.asset` 中登记或替换 prefab_id 对应的预制体。

- 根物体是地面中心锚点，缩放为 1。
- 入口统一朝局部 **-Z**；生成器负责整栋建筑旋转。
- `BuildingFootprint` 保存实际占地尺寸、层数和是否为商铺。占地是包含阳台、雨棚等突出部分的完整外接范围。
- 本版每块地为 8×8 米，建筑完整占地不能超过 7.95×7.95 米。若换更大模型，必须先调整地块布局，不能只填一个较小的占地数字。
- 制作好的几何按材质合并，减少渲染对象。可替换整个预制体，或替换其材质 / 合并网格；不建议在合并网格内逐扇改窗。

## 程序职责

- `CityBlockLayout`：固定示范路网、地块分配、入口朝向、高度限制、按条件与权重选择建筑。
- `CityBlockKit`：道路、绿化、道具、建筑目录和 CSV 的资源引用。
- `BuildingFootprint`：单栋建筑的空间信息，与显示网格分开。
- `SpawnRules`：沿用原型的表格校验、条件筛选和加权抽取。
- `CityPreviewRendering`：仅在样板场景激活时应用独立渲染配置，关闭后恢复原来的渲染配置。
- `CityKitBuilder`：编辑器制作工具；已存在预览场景时拒绝重建覆盖。平时调表用 Rebuild static block，不需要重新生成素材。

## 已知限制

这是一块固定路网的静止视觉样板，尚未接入无限滚动城市。地块与公园位置仍由示范布局确定。它验证的是道路连接、建筑体积、朝向和资源分离，不能代表最终美术效果。

本机 Unity 2022.3 的批处理渲染中，开启批处理优化曾出现跨材质颜色错误；样板配置暂时关闭 SRP Batcher 和材质 GPU Instancing，采用已验证的显示结果。此配置不修改原项目全局渲染资源。后续性能优化应在目标窗口与正常运行环境中重新验证。
