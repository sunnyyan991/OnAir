# OnAir 美术风格

维护：lumi。更新：2026-10-05。

本文件是项目总体美术方向与当前 UI 标准的入口。具体建筑、物体像素密度、材质和云影制作继续使用既有专项文档；本文件不替代或重写它们。仅记录已知内容，字体文件、未批准的默认数值及其他缺项不补写为规则。

## 已确定的项目方向

- 固定等距视角下的日式城镇观景：建筑、道路、水系、绿地、飞行中的小飞机与三层像素云构成画面。保持轻松、安静的飞行气质。
- 画面以灰米色建筑、绿地、深蓝绿水面、奶油白云层为主要关系；红白小飞机是小面积视觉重点。该描述来自当前实机参考和本轮批准图，不是各类资产的新色值规范。
- 物体轮廓与色块保持清楚，UI 使用规整硬边、细高光与短距离右下硬阴影。UI 面板承托文字，不给世界画面添加整屏模糊或另一套像素网格。
- 不引入 RPG 奇幻、机场管理、雷达仪表、霓虹科幻等其他风格。新 UI 继续与现有 FlightPanel 协调。

专项标准：[建筑美术流程](BuildingArtWorkflow.md)、[建筑配色](BuildingColorStandard.md)、[物体像素密度](PixelDensityStandard.md)、[像素资产表现](PixelArtV2.md)、[云层](CloudLayers.md)、[云影连续性](CloudShadowContinuity.md)。物体的像素密度规则不直接套到屏幕 UI 或字体上；本轮不改动资产制作规范。

## 本轮已确定的 UI 标准

### 标题、存档与署名

- 标题以 OnAir 品牌为主视觉，菜单位于左侧纵向排列。按钮严格为 **START / LOAD GAME / CREDITS / SETTINGS / QUIT**，保持等宽、间距一致。
- 标题 Logo 采用最新选定图中的 **OnAir** 大小写关系：奶油色实心像素字，下面是短虚线航迹与向右的小飞机。字标使用独立像素掩模，保留原 HUD 英文字库。
- 标题按钮采用深青底、像素切角、双层细边及右下硬阴影。默认 START 用淡金边框和左侧箭头强调；鼠标悬停其他按钮时，强调跟随该按钮。字标和按钮仅在标题页使用这套独立绘制，不改变运行控件布局。
- 背景沿用项目城镇与云的景观，不让菜单覆盖画面中心的飞机。标题页与存档页可以用深色承托或局部压暗背景保证文字清楚，不改变运行 HUD 的既有布局。
- LOAD GAME 用于继续已有行程。存档行保持名称、群系、路线里程、最后保存时间的清楚层级；新建与读取页分别为 **NEW FLIGHT**、**LOAD GAME**。三槽仅为效果图示例。
- 空槽使用 **EMPTY SLOT**。在读取页，空槽和不可读取状态不能在视觉上冒充可用存档；禁用 LOAD 时保留可辨文字。
- CREDITS 仅在标题页出现。用户署名准确为 **Moby、Kisa**；不自行补职位、团队名或其他作者。

### 运行 HUD 与 SETTINGS

- 保留左侧 **LOCAL TIME、当前群系、SEED**；右侧保留 **FLIGHT CONTROL、ENVIRONMENT、EXPLORE / CHOOSE BIOME、WEATHER、TIME OF DAY 拨盘、AUTO FLIGHT、NEW SEED、RELOAD CSV、飞行状态、WORLD STATUS、BLDGS、LEG、ROUTE、FPS**。按当前条件显示原有折叠与详情内容。
- 保留已有存档反馈及条件显示的 **PREVIOUS FLIGHT**。概念图遗漏这些内容，不构成移除授权。
- 仅在左侧 SEED 下新增 **SETTINGS + / SETTINGS -**，沿 LOCAL TIME 左边对齐，向下展开。右侧控件不搬家，不改成顶部栏，设置入口不依赖 FLIGHT CONTROL 是否折叠。
- 展开区严格为 **SAVE GAME / DISPLAY / BACK TO TITLE / QUIT**；BACK TO TITLE 前有分隔线。运行中及其子页没有 CREDITS，也不重复添加天气、昼夜或暂停入口。
- DISPLAY、确认框等使用同一面板语言；长文字不贴边、不越框，退出/覆盖确认的 CANCEL 具有明确可见的默认焦点。行为和测试由程序负责。
- 保存反馈使用准确英文状态，成功与失败可辨，不能用成功色及文字伪装失败。具体反馈状态以程序真实结果为准。

### 游戏内文字

- 游戏 UI 全部英文。沿用清晰的像素英文字与数字风格；标题、按钮、存档摘要与小状态文字保持字号层级。
- 原有 HUD 的文字与布局不因新增菜单而缩小或改形。LOCAL TIME 保留 **HH:mm:ss** 的当前现实时间；存档时间是列表元数据，不代替当前时钟。
- 日期、路径提示或长确认文本需要能读清并完整展示；不为装饰将文字压成无法分辨的像素。原有存档小反馈可保留现有小字表现，本轮不强制将其重新制作成另一套字库。
- 字体名称、字体文件与许可尚未由批准图确定，不凭图片猜定。字形可见性与大小必须以真实目标窗口截图核对。

## 已替代与待定

- 已替代：运行顶部栏、隐藏或迁移原控制区、中文菜单、运行中 CREDITS、只有两项的 SETTINGS 展开区。当前有效展开区为 SAVE GAME / DISPLAY / BACK TO TITLE / QUIT。
- 已确定：复用现有自动存档能力并继续行程；不把此前“没有存档系统”的旧稿当当前事实。
- 待定：具体 UI 字体文件、未定的 DISPLAY 默认值、最终支持窗口下限。效果图样例槽数、世界种子、建筑数、里程与时间不是规则。
- 最新真实截图与评审结论维护在 `local-work/ui-implementation-2026-10-05/lumi-review.md`。当前批准图不代表程序实现已通过视觉验收。
