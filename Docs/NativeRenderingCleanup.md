# 原生渲染、资产清理与性能收尾

本轮以保留当前城市构图、可见建筑数量及楼型多样性为前提，移除整屏像素化并减少重复工作。

## 已完成

- 删除 PixelPresentation、PIXEL 2X / 3X 菜单和低分辨率放大路径；FPS 独立显示，Main 使用原生输出。
- 核查公寓材质：只有 1/10 材质组接入试验贴图；该图是墙面噪声，并非像素立面艺术。试验材质改用正常昼夜照明与投影，旧 UV / 亮度分格 shader 归档。
- 连续地图只在新地块发布前初始化窗灯，取消每次加载新地块后遍历所有旧建筑的重复扫描。
- 外墙颜色复用共享材质，取消逐栋 MaterialPropertyBlock。一个固定种子短测中，2,324 个外墙渲染组件使用 35 个共享材质，覆盖参数为 0。
- 复用每帧视野计算的集合；地面网格构建减少临时数组；飞行安全采样与群系预览的独立缓存定期修剪。
- 高架走廊提前分帧规划，避免在选择建筑地块时突然同步规划整条高架。线路、概率与建筑库不变。
- 独立游戏夜景复查发现窗灯发光变体被打包裁剪。已为被引用的窗灯源材质显式保留发光变体，并加入独立画面中的暖色亮窗检查；白天仍由运行时将发光强度设为零。

## 资产清理

共归档 21 项及其 .meta：6 栋零权重旧 City 楼、10 个废弃材质、1 张废弃贴图、3 个旧像素截图工具、1 个旧试验 shader。保留 64 项共享依赖，当前 13 种日式建筑完整保留；12 栋 Coast / Desert 兼容楼仍有规则引用，没有删除。

[归档说明与恢复方法](../Art/Archive/2026-09-24-retired-city/README.md)；[逐项清单](../Art/Archive/2026-09-24-retired-city/manifest.tsv)；[全项目引用审计](../Art/Archive/2026-09-24-retired-city/asset-audit.tsv)。清理未引用资产主要改善管理，不能把归档数量当成帧率提升。

## 已取得的验证证据

- 工程结构、场景/预制体脚本、规则表、资源目录检查通过；Windows 开发版构建成功，0 个构建错误。
- 高架在 3 个固定种子、36 个区域的路线记录与优化前逐字一致。
- 城市和丘陵各巡航 1,800 个实际帧，共 120 秒固定步长模拟；独立摄像机地面射线检查、换种子覆盖检查通过，可见缺块及巡航紧急同步补块均为 0。
- 同一巡航路线的最长单次生成步骤：优化前 114.70 ms，分帧后 10.37 ms。它是生成步骤耗时，不是平均帧时间或总帧率提升倍数。
- 编辑器截图读回、群系瞬移会制造额外同步等待；相关最大帧时间不能直接当作正常游戏巡航帧率。

原始结果：[优化前](../Art/Reviews/NativeRendering/streaming-before.txt)、[优化后](../Art/Reviews/NativeRendering/streaming-after.txt)。

## 最终独立程序验收

RTX 2060 / i7-9750H，Windows 开发版，640×480 和 1280×720 各 20 秒晴→大雨→晴；五个时段选择、实际夜景亮窗、三次 NEW SEED 全部通过。可见缺块和巡航紧急补块均为 0。暖色亮窗从实际输出中检出 19,729 个像素，并人工复看截图确认。

本次首屏世界数据准备约 6.30 秒，不包含首次强制离屏绘制；三次换种子为 3.69、2.91、4.85 秒。首次启动和换图仍有同步等待。

本测试每帧强制绘制原生尺寸并读回以确保 GPU 实际工作；**计时包含同步读回，不是正常窗口 FPS，也不是功耗或长时间稳定性结论**。记录如下，用于暴露卡顿而非宣传帧率：

| 测试尺寸 | 帧间隔中位数 | P95 | 最大值 | Unity 已分配内存 |
| --- | --- | --- | --- | --- |
| 640×480 | 5.09 ms | 10.45 ms | 333.09 ms | 129 MiB |
| 1280×720 | 12.57 ms | 20.81 ms | 32.14 ms | 140 MiB |

仍记录到偶发长帧，不能宣称所有卡顿已消除。后续应区分首次绘制、驱动、资源上传和日常巡航的开销，再针对真实窗口及用户常用分辨率测量。

## 边界

原生渲染在高分辨率下可能比低分辨率画面放大消耗更多 GPU；本轮优化没有靠减少屏幕内建筑、降低种类或改变城市分布来换性能。

首次启动和 NEW SEED 仍需同步准备首屏，尚未做到无等待的后台换图。长时间运行的散热、功耗和多分辨率稳定性需继续验证。背景窗口可能不真正绘制画面，因此不能用后台空转得到的极高 FPS 作为成绩；最终独立程序验收会明确记录是否实际渲染以及计时边界。
