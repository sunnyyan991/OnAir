# 道路车辆与城市绿地资产（2026-10-04）

本轮已接入 Main。日夜截图在 `Art/Reviews/CityLife/`，统一资产目录仍为 `Art/AssetLibrary/index.html`。

## 车辆

- `TRN-VEH-001`：简化小型汽车，长 2.75 米、车身宽 1.25 米。白色前灯、红色尾灯；白天只显示材质本色，夜间按原色自发光，日夜过渡跟随世界时间。
- 浅色莫兰迪 50%、深色莫兰迪 30%、跳色 20%。这是每辆车的抽样概率，不要求每一屏恰好达到该比例。
- 对象池上限 96 辆，覆盖当前已加载道路；不等于屏内保证有 48 辆。速度 2.5–4.5 米/秒。一个 `CityTraffic` 统一推进，不添加刚体、碰撞体或实时灯光。
- 从 `ContinuousWorldLayout.RoadFootprints` 的实际地面道路面片建立 2 米网格，不在草地、水面或楼顶凭空画路线。优先沿左侧车道直行，路口随机选择转向；前方检测距离增至 8 米，以加减速度平滑启停，转弯速度和转向角速度减半。
- 目前是装饰性交通，支持地面和两层高架，沿高架行进方向靠左，总额度中最多 32 辆用于高架。新高架载入后会从屏外地面车辆补充名额。**不包含斜向接驳桥、交通信号、目的地寻路或完整交通仿真**。无法连通的道路末端会停车；离开加载范围后回收。
- 开场允许已有车辆出现在道路上；后续补车从屏幕外进入。路网每 0.5 秒只登记新地图块、移除退场地图块。使用全局地图坐标，跨地图原点更新时继续跟随，不与飞机的相对高度逻辑绑定。
- 车灯标记为 `Headlights` / `Tail lights`，共享独立白/红发光材质；不参与建筑的随机窗户熄灯逻辑。

PUB-SHR 为“寺社 / 宗教建筑”统一类目，涵盖神社和寺院，不把清水寺称为神社。大型款借鉴清水寺的宽屋顶与木构舞台，并按游戏尺寸重新组织，未使用第三方贴图。建筑参考：[清水寺官方结构介绍](https://www.kiyomizudera.or.jp/en/learn/)。

生成规则在 `WorldGreenSpaces`，独立随机盐，不消耗既有建筑抽选随机序列。城市 / 镇区生态权重之和达到 0.65 才参与。每地块 48% 获得一次尝试机会（不是 48% 必定放入资产），依据候选类型、尺寸及朝向寻找落点，较大资产放不下时回退至公园或微型神社。每地块至多一个，不会铺满绿地。

完整占地按最多 2 米间隔检查，必须全部为平坦 Park：拒绝农田、水岸、斜路、低层高架及桥梁保留区。地块边界保留 1 米余量。先登记占地，再生成自然树木，避免树长进球场和建筑。占地加入人口计划，使第二层高架能够检查建筑高度并避开支柱占位。现有临街建筑不会被拆除。

原五款均有四向像素烘焙。当前 ENV-PARK-001 改由程序化几何生成，不再放置旧固定公园；检查实际灰路四边围合，浅绿和深绿均可参与，绿地面积至少 64 平方米且覆盖地块至少 55%，合格地块 55% 尝试。主径约 1.25–2.25 米，支径 0.9 米，家具按面积限制在 2–12 件，仅清理路径及家具附近的树木。详见 `CityLifeV2.md`。

石灯笼明确标记为彩色自发光，不随机熄灭；没有把实心木门伪装成发光窗。静态原始模型按材质合并后再保存，避免新增几百个阴影 Renderer。

`buildings.csv` 的 176–180 保持数字 ID，街道池权重为 **0**；这只代表不参与临街建筑抽选，不代表停用。它们通过三个 WorldKit 的 `greenSpaceAssets` 和绿地专用规则生成。资产列表另行显示“绿地专用生成”，避免把街道权重误当成出现概率。

## 检查和后续调整

- `CityLifeAssets.Complete`：生成、四向烘焙、日夜截图、分布检查。
- `CityLifeReview.Run`：Main 实际启动、车辆、地图完整性、日夜画面及耗时采样。
- `CityLifePlacementAudit.Run`：四个种子、768 个区域的完整占地检查；记录各款数量和首个示例坐标。
- 修改车量：`CityTraffic.Capacity`。修改颜色概率：`ColourFamily`，色板在 `Start`。修改绿地机会与候选权重：`WorldGreenSpaces.Prepare`。
- 修改占地必须同时修改生成器几何与 `BuildingFootprint`，不可只缩小检测框。资产表更新后执行 `Art/AssetLibrary/Update-AssetLibrary.ps1`。

原脚本及目录表快照位于工作区 `Checkpoints/TrafficGreenSpaces`。没有改动飞机高度、摄像机、云层参数、原建筑夜间随机亮灯规则。
