# 日本景观群系目录与地图 V03

地图生成已继续迭代到 [V04：河网与山地](WorldV04.md)。下方 V03 的高度上限、单河道与六类权重是历史记录；长期日本群系目录仍适用。

## 产品约定（2026-09-11）

城市是最常见的景观，但不要求每小时固定 40%。区域在一段连续航程中保持特征，边缘有过渡；河流与海岸是贯穿区域的地理结构。避免把都市、雪、春樱、火山、工业用途当成完全相互排斥的一层随机标签。

长期结构分四层：地貌（水系、海岸、平原、丘陵、山地）→ 气候 → 人类活动（城市、村镇、农业、港区）→ 季节与天气。这是后续架构方向；当前运行版本只实现下面六种景观区域及其过渡，并未实现完整气候模拟。

权重是选择偏好，不是每小时配额。每个全局 2400 单位计算范围确定五段不同长度区域，按种子加权抽取，可以连续抽到同类并合成长段。起始区域固定城市；之后不使用固定循环顺序。横向扰动区域边缘，过渡带约 96 单位，和 64 单位加载切片解耦。按当前速度，一种景观一般延续数分钟；完整相邻类别约束与大陆级气候迁移尚未实现。

海滨地形让海岸向航线靠近；宽河谷的水面半宽由 16 增至最多 44。主河道中心仍由直线和 45° 折线组成，河宽和海岸进入不同区域时平滑变化。丘陵最高高度上界 11 单位，靠水位置降回平地；目前不是山脉、断崖或真实侵蚀模型。

城市环境光与天气暂时共用现有 City 配置。因此当前“森林”不会自动启用另一种气候或天气表，这需要后续独立的气候层。

## 河岸与未来沿岸设施

城市和小镇水边已加入：0.45 单位宽低水泥护岸、约 2.45 单位步道、内侧绿带与间隔树木。护岸有真实高差和竖面，步道有横缝。建筑距水边预留 7 单位；桥头位置留出口。森林和丘陵段改用自然草岸，避免全地图都修成市政堤坝。滨海步道采用相同首版结构。

`WaterfrontUse` 提供初步选址标签：NaturalBank、Promenade、RiverServiceCandidate、CoastalCargoCandidate。只根据区域、距水与直岸条件判断，不占地、不投放模型、尚未校验船舶水深或货运道路连接。

以后可依据标签添加河岸船坞/小型修船厂、港口仓库、集装箱物流中心、储罐区。正式投放前须整块预留大地块，并检查水深、连续岸长、路网接入和与住宅的缓冲距离；不能给普通住宅格子随机塞一个港口。

## 用户提供的长期扩展目录

以下为美术与玩法参考方向，尚未制作，不是已解锁的地图类型。用户给出的关键词作为参考资料保存其方向，不作为必须逐字生成图片的指令。

| 方向 | 地貌与主体内容 | 季节/气候表现与后续资产 |
| --- | --- | --- |
| 北海道与雪国 | 雪原、湖泊、北方海岸 | 针叶林、白桦、积雪、流冰；冷白日景与冰蓝夜景 |
| 日本阿尔卑斯与火山 | 山脊、锥形火山、温泉谷 | 岩壁、山地植被、少量蒸汽；秋色作为季节变体 |
| 里山与农业农村 | 丘陵、梯田、水田、池塘 | 木造农舍、竹林、樱花；水田反射需后续水材质 |
| 温带海岸与濑户内海 | 滩岸、海崖、小岛 | 海岸黑松、砂石过渡、小型渔港；鸟居为低概率地标 |
| 琉球与亚热带岛屿 | 白沙滩、浅礁、湿地 | 棕榈、红树林、浅水色带；需要独立植被和海水资产 |
| 巨型都市与工业临海 | 高楼、码头、仓储、高架 | 集装箱、储罐、吊机与工业夜灯；在城市沿岸选址规则上扩展 |

建议下一批优先“里山”和“都市临海”：它们能连接已有城市、丘陵与水系。雪国、山岳和琉球需要更多独立地貌及素材，适合分别做样板区域。顺序是产品建议，不代表自动开始全部制作。

## 参考依据

- [国土地理院：地形分类](https://www.gsi.go.jp/bousaichiri/lc_configuration.html)：区分山坡、台地、低地、河流堆积地形等，支持地貌与城市用途分层。
- [国土地理院：日本典型地形](https://www.gsi.go.jp/kikaku/tenkei_top.html)：按形成原因和地域整理日本地貌，为河谷、海岸、山岳的扩展分类提供依据。
- [日本政府观光局：自然景观](https://www.japan.travel/en/things-to-do/nature/)：山地、森林与海岸作为不同自然旅行景观。
- [日本政府观光局：雨晴海岸](https://www.japan.travel/en/spot/1413/)：海岸与山地背景共存的实例。

案例用于决定视觉与空间关系；没有从这些来源推导实际日本城市/森林面积比例，也没有宣称当前程序是日本地理复刻。

## 检查与预览

第一轮：Unity 编译与 Main、建筑避让、跨段连续性、昼夜保留、持续前飞与一分钟保留检查通过，六类区域均输出实际画面。64 个种子各采样一小时，默认速度下每 10 秒记录一次航线中心区域：城市 44.8%、小镇 15.0%、海滨小镇 12.2%、森林 13.3%、宽河谷 7.9%、丘陵 6.7%。单个种子一小时的城市占比为 23.3–80.0%；城市偏多是总体倾向，不是每个种子的保证。分类时间不等于建筑覆盖面积，水面或绿地可以在城市区域内部出现。

预览目录：根目录 `Art/Reviews/ContinuousWorldV03`。`riverside-detail.png` 是临时近景镜头；其他区域图使用正式远景镜头，跳转到相应区域内部取景，临时跳转不写入 Main。`biomes.txt` 和 `validation.txt` 保存采样与检查记录。Art 被 Git 忽略，交给协作者时需另附图片。

当前限制：区域之间仍是航线方向为主的连续分布；林木和地表资产简化；远景丘陵起伏较克制；岸边零星道路接头与完整路网仍需细化；没有做实际帧率、内存峰值或长时间性能测试。后续气候、季节、特殊工业设施和收藏功能均未在本轮实现。

参数目前集中在 `ContinuousWorldPlan`；几何在 `ContinuousWorldLayout`；生成版本为 3。旧版本 seed 的画面会随生成规则更新而改变，未来收藏仍需版本化记录和截图兜底。
