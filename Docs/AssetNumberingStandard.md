# 建筑资产统一编号规则（2026-10-02）

统一查看与命名入口为 Art/AssetLibrary/index.html。assets.json 和 categories.json 是该目录的数据来源；修改一次后运行 Update-AssetLibrary.ps1 同步 HTML、台账和旧新编号映射。批次只记录制作过程，不再定义类别或编号。

编号格式：大类-子类-三位序号。例如 RES-APT-001 是住宅类 / 中层多户公寓 / 第001款。序号在子类内递增，不回收；不是层数、颜色或制作批次。展示名称为“编号 中文款式名”。新文件及新预制体采用编号加英文名称，如 RES-APT-011_CourtyardApartment。

| 大类 | 子类 | 定义 |
|---|---|---|
| RES 住宅 | APT 中层公寓、LOW 低层集合住宅、DET 一户建、ROW 长屋 | 按居住结构区分 |
| COM 商业 | FOOD 餐饮、SHOP 店铺、MIX 商住复合、OFF 办公、MALL 商场 | 按主要用途区分 |
| PUB 公共服务 | MED 医疗、EDU 教育、CIV 社区行政 | 不混入商店池的美术分类 |
| TRN 交通 | STA 车站与交通建筑 | 根据交通条件布置 |
| ENV 环境 | PARK 园林绿地资产、FAC 公园街道设施 | 公园地块与内部设施分开 |
| LND 独立地标 | SPECIAL 特殊地标 | 普通高层仍按实际用途编号 |

高低层、年代、配色、所在街区、版本及制作批次是属性。办公塔楼继续属于 COM-OFF，医院高层继续属于 PUB-MED，不再因高度被归入混合地标池。

已迁移34个目录条目，其中28款已有运行资源、6款规划中。A系列归RES-APT，B系列归RES-LOW；C05归RES-ROW，其余C系列归RES-DET。D04诊所归PUB-MED，其他旧D系列按餐饮/零售/商住分开。旧E01–04归COM-OFF，旧E05–06归COM-MALL。完整对应表由工具导出至 Docs/AssetCodeMigration.csv。

运行纯数字ID、旧CSV资源键和已有Unity路径作为兼容标识保留，目录编号不改变运行抽选概率。已有模型生成器和尺度清单还依赖旧资源名称，因此此轮不直接重命名Unity资源；实际资源路径在目录中明确显示，后续资源迁移必须连同生成器、烘焙路径、验证清单及GUID引用一起更新，不能仅改文件名。旧编号仅出现在追溯记录和历史文档，不再用于新提案。

用途分类修正不等于运行概率已迁移：诊所目录已经归医疗，当前运行仍沿用历史Shop抽选，必须明确登记，后续公共医疗生成规则接入时另做验证。规划中的办公与商场分别承接Office/Retail类别权重，不按六款合并百分比直接写入。

同一资产改色、修细节和结构修复保持编号、增加版本；新增可同时保留的独立款式才分配新号。取消或退休的编号保留记录，不重新分配给另一栋建筑。分类纠正保留legacyCode与运行ID建立迁移映射。
