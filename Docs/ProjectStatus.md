# 项目全盘进度 · 2026-09-26

目前是可以持续飞行、切换景观与天气的 3D 氛围游戏原型。地图和运行框架已有基础；美术还没有达到完整的《西奥小镇》式像素资产效果，不宜称为最终成品。

## 本轮交付

详见 [原生渲染与清理记录](NativeRenderingCleanup.md)、[当前配置与操作](Configuration.md)、[像素材质核查](PixelMaterialWorkflow.md)。历史文档只是当时的阶段记录，不代表其中所有功能已经最终完成。

本轮物体像素外观已接入 Main，Windows 构建和独立程序验收通过。连续飞行、晴雨变化、五个时段、夜间亮窗和三次换种子均已检查。新的截图与验收结果见 Art/Reviews/PixelCity；换种子仍需约 3.45–4.36 秒，测试仍录到偶发长帧。长期功耗尚未验收。可直接打开 Builds/WindowsNative/OnAir.exe，或使用 Unity Main。

## 下一阶段建议

现有城市建筑已按统一像素规则重整窗格、阳台、屋顶色块并减少微小部件。下一步以代表楼型继续逐栋做外观差异和精修，完善店铺招牌、屋顶与立面辨识度。地图框架暂时保持稳定，以便辨别改进来自美术还是生成规则变化。

随后制作里山和工业滨水各一个代表区域，补充独特建筑与植被；最后推进收藏风景、长期运行和正式副屏体验。每一轮都交付可 Play 的效果与明确验收记录。


第二轮的片体架构审核、艺术依据、适用边界与随机窗灯验证见 [PixelArtV2](PixelArtV2.md)。当前交付以该文档和 Art/Reviews/PixelArtV2 的最终报告为准。
