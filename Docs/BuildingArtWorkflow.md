# 建筑美术共创流程

当前颗粒度标准见 [物体像素密度标准](PixelDensityStandard.md)：所有建筑与独立像素环境资产统一4 PPU。效果图只用于楼型与配色确认，不作为提高实物密度的理由；实物必须与旧楼同镜头、同尺度验收，不能为了展示细节单独提高某款的像素密度。

你负责选方向、判断“有没有日本街头的感觉”；我负责参考整理、效果图、模型、材质、入库和地图验证。不需要你先学建模，也不需要你在多个生成工具之间搬文件。

## 第一轮先讨论这些类型

这不是一次全部制作的清单。项目已有十三种建筑，应优先重做代表样板，再逐步替换，避免不断叠加相似楼型。

| 类型 | 重点辨识特征 | 建议体量 | 街区中的作用 |
| --- | --- | --- | --- |
| 狭窄一户建 | 坡顶、小阳台、侧墙紧贴邻居 | 2–3 层，窄面深进深 | 成片住宅与高楼脚下的尺度对比 |
| 长条出租公寓 | 连续阳台、外廊、外露楼梯 | 3–6 层，长宽比约 1:3 | 打破方块楼的重复 |
| 窄面办公楼 | 竖向招牌、窗带、小面积屋顶设备 | 6–10 层，长宽比约 1:2 | 商店街与办公区的竖向节奏 |
| 街角商住楼 | 一楼店面、转角入口、上层住宅 | 3–5 层，接近方形或短长条 | 让路口有生活感 |
| 百货与商业综合体 | 宽大基座、少量大招牌、屋顶机房 | 5–10 层，大占地 | 低频出现的大体量 |
| 旧式木造店铺 | 暗木、瓦顶、雨棚、窄招牌 | 1–2 层，窄而深 | 打破水泥楼的材料重复 |
| 地标与高层塔楼 | 独特轮廓、清晰顶部、基座退台 | 单独定义，低概率 | 稀有的城市记忆点 |

建议首批从前三类各选一栋。它们在高度、长宽比和生活气质上差别最大，容易判断整座城市是否更丰富。

## 每一栋按五步推进

1. **类型卡**：先写清用途、年代、层数、长宽比、主材料、适合街区，以及你最在意的两三个特征。暂时不纠结空调数量等小细节。
2. **效果图 A/B**：同一栋只给两个方向，使用相同视角、日照和画面尺寸，避免因为光影不同而选错模型。至少包含放大的建筑图和实际游戏尺寸下的小图。
3. **你选定方向**：反馈可以很口语，例如“选 B，但阳台更深、墙不要这么白、招牌少一点”。我把反馈合并成该建筑的制作约定。
4. **做游戏样板**：实现三维模型，在现有像素渲染里查看。效果图若使用生成图片，它只是设计参考，不代表图片可以直接变成可用模型；我负责后续建模与接入。
5. **放进小街区验收**：先看一条街，再按概率进入连续地图。提供白天、夜晚，以及行进过程中的画面，检查重复感、体量、道路朝向、邻楼间距和像素杂点。

你主要在第二步和第五步做判断。中间建模、文件管理、测试都由我处理，不需要逐项批准技术动作。

## 固定每次交付的内容

- 一页建筑卡：类型、版本、用途、外观特点、待确认事项。
- 两种可比较的概念方向，选定后保留最终方向图。
- 源模型与物体像素外观的截图，以及街区实景。
- 更新后的预制体、材质、建筑表、目录和概率设置。
- 验证记录：占地不冲突、最高点计入飞行安全高度、夜间窗灯正常、近远景没有明显闪点。

新资产沿用现有分类和稳定编号；修改旧建筑保留其 GUID 和引用，不为每次改色复制一套楼。记录“提案 / 制作中 / 待看样 / 已确认”，概念图保存在 Art，运行资源保存在 Unity Assets。

## 控制细节与重复

先确认远景轮廓和窗墙节奏，再添加阳台、楼梯、设备等中等细节。小于游戏中一两个像素的栏杆、白色边条，不靠不断增加几何来表现；优先合并成稳定的材质色块。

变体可以改变屋顶形式、阳台布局、材料和招牌，但不把同一栋楼随机涂成很多颜色充数。住宅成片、商业沿街、塔楼低频、滨水设施靠水，各类出现规则与模型一起交付。

按用户最新约定，每批六款。先验收它们共同组成的街区，再扩展下一批。你只需要说出偏好的类型与外观，我来维护这套流程。


固定俯视像素外观的限制和源模型保留规则见 [像素资产架构自查](PixelArtV2.md)。新增素材始终保留三维源模型、占地与高度；不要把效果图或单张片体当成完整建筑资产。
