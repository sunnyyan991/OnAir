# 飞机固定绝对高度

2026-10-03：用户确认正式采用固定绝对世界高度130米，跳过地形爬升及上下起伏。相机/地图加载锚点固定65米，显示模型沿相机中心视线调整至130米，因此保持居中及原有相机角度和范围。AircraftHeightPreview保留历史类名作为实现入口，当前为正式启用配置。

上述固定高度用于正常巡航。机场访问期间由独立起降流程控制进近、接地、地面滑行和离场爬升，不套用巡航的固定高度；离场后恢复130米。详见 [机场飞行流程](AirportFlightCycle.md)。

正式高度统一定义在AircraftHeightPreview。地形最高120米；建筑以实际模型最高点及标注高度检查，超过120米的资产仅在运行时排除，不缩放或修改原资产。10米净空作为机体下方余量；当前建筑布置只允许零高度地面。相机与云层仍使用65米锚点。固定高度启用时跳过原爬升计算，历史开关关闭后可恢复旧逻辑。未修改正式场景和飞机预制体。

恢复方法：将 Assets/Scripts/Flight/AircraftHeightPreview.cs 的 Enabled 改为 false，再重新进入 Play。组件仅在运行时安装，不写入场景。原有进度和全部资源保持原样。
