# 小型飞机资产

本批先使用内置 image_gen 生成同尺度效果图，再制作独立模型。用户授权无需等待图或模型审批；目标是机场停放装饰和以后可用的飞机外观素材。本批不增加飞机选择界面、不替换当前玩家飞机，也不绑定旧客机专用运行组件。

这些是本游戏的设计尺寸，不代表对某个真实机型的精确复刻。以当前游戏飞机约7.8米机长、10米翼展为比较；小型私人机仍按小飞机尺度制作。

实际网格检查：机长分别8.02、7.22、12.02米，翼展和总高与表格相符；轮胎最低点均为0。三角面数分别1406、1616、2377，包含预留导航镜片；C的数字已计入2026-10-15机头与尾翼更新。厘米级机长差异来自螺旋桨/机头端点，未使用补偿缩放。

## 模型与替换接口

- 米制，根节点缩放为1、前方为本地+Z、轮胎接地点为本地y0。新增停机模型也使用原尺寸，不通过整体缩放适配机坪。
- 运行资源位于 `OnAir/Assets/Prefabs/Characters/SmallAircraft` 和 `OnAir/Assets/Art/Aircraft/SmallAircraft`。每款独立预制体和具名部件，保留机翼、座舱、起落架、螺旋桨/发动机及灯具分组。
- 使用 `OnAir/Cloud Receiving Lit`；机身、玻璃、轮胎正常受光。静态停放时发动机、螺旋桨和导航灯均关闭。单资产夜图可展示预留导航灯；这不等于停机时开启飞机灯。
- 可复用的飞行外观仍需后续接入当前飞行表现、转动螺旋桨与导航灯控制；本批不强行挂载已有A330专用rig。

## 机场停放

两款螺旋桨机停在既有水泥机坪 `(86,-14)`、`(109,-14)`，均朝本地+Z，独立停机线。它们位于航站楼北侧、动态地勤停车位南侧，避开飞机滑行中心路线、倒库半圆和地勤进出通道。机场原停放飞机保留；私人机暂不重复摆放。

水泥地西边中央直接贴齐柏油路外边缘，三处入口不再保留尖舌或碎草凹口；机坪两端贴合现有圆弯边界。原滑行路线和夜间射灯保持。

上述检查已通过，Main中两架新增停机模型正常显示且夜间不自发光。对比图只调整相机范围修正裁翼，没有改动模型或重新执行整套机场流程；未打包，未写玩家存档。

## 2026-10-15：C机头与尾翼更新

C的鼻部保留小圆尖，前段逐渐放宽再接入座舱肩部，避免长直圆锥或过早膨胀的半球形。双片前窗与侧风挡直接分割机身原三角表面，避免大玻璃平片横跨曲面、被不透明机身遮住；中间保留细白框。

深蓝垂尾根弦约2.16米，前缘后掠约35.6度；白色水平尾翼前缘后掠约26度，安装高度3.52–3.55米。深蓝垂尾穿过白色翼根，顶部增加短小流线连接帽，最高点仍为3.8米。两侧平尾均与蓝色垂尾、连接帽交叠，避免柱状垂尾止于白色横杆下方的观感。

本轮只重建C的机头和尾翼相关网格，复用原资源GUID；A/B、共享材质以及C的主翼、发动机、起落架、客舱窗和锚点均通过依赖哈希未变化检查。C仍为11.8×3.8×12.023米、接地点0，2377三角面。仅抓取C日夜、机头/尾翼近景及同尺度对比图，未重烘A/B或运行机场流程。记录见 `SmallAircraft/jet-front-validation.txt`。
