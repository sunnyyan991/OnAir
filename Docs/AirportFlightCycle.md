# City / Airport：日式小机场运行规则

2026-10-14。当前运行资产为 ENV-AIR-002 SmallField。旧羽田式机场模型、资源和源码保留，快照见 [归档](../Art/Archives/Airport/Haneda-2026-10-13/airport-source-snapshot.zip)。

## 布局与比例

- 机场核心地块210×330米，源坐标围栏范围x[-45,165]、z[-165,165]；单跑道240×18米，固定圆弧半径12米、滑行铺面宽12米（给约10米翼展及转弯扫掠留余量）。资源加载范围独立于围栏，包含有限的入口连接搜索范围，不用它扩大清地。
- 玩家飞机使用既有Plane/FlightView模型和2.7倍原比例：机长约7.8米、翼展约9.94米。其他飞机直接复用同一真实体量。
- 航站楼18×36米、主厅6米、观察室10米；机库26×28米、门净宽22米/高6.5米。共用87×156米混凝土机坪，机坪与机库地板均高0.19米。
- 停车场50个真实车位；六座独立辅助楼集中于连续水泥服务场，保留燃油设施、物料架和轮挡。2米铁丝网围栏、陆侧入口、风向袋、PAPI、顺序进近灯、跑道端灯和机坪照明随机场整体旋转；跑道端保留低易折断边界/净空。
- 模型跑道内部仅画白色标线，黄线裁在跑道外。全部飞机滑行路线及固定画线来自SmallAirportNetwork，不能用访问时叠画修补连接。

## 陆侧接入、住宅与水系

- 实际入口位于源坐标(165,-54)，向围栏外连接既有世界道路。优先在192米内选择可用的直线或折线接入；没有合适结果时允许一次256米范围的沿水接入搜索，选择连续、可落到真实道路的路线，不留下孤立路段。
- 接入路宽4米，门口高0.2米，末端平缓回到0.09米。跨水使用有桥墩和护栏的桥面；必要的转弯以约14米圆弧连接，共用铺面接点。常规路线跨水段单段最多64米、合计80米；沿水备用方案最多两段、合计160米，每约12米设支撑。地面交通不进入抬高的桥面及坡道。
- 围栏外不再内置一圈复制的住宅街，沿用世界自身的道路、自然地形和住宅生成。围栏周围96米范围按住宅区安排，最多4层且高不超过16米；保留建筑与围栏间隔、窄进近净空及接入道路，机场内部不生成城市建筑。
- 机场只占用核心围栏范围。世界地面、水面及护岸在边界按精确多边形或线段差集裁剪，保留边界外原有岸线；接入路与桥面在独立阶段绘制，不参与核心地面裁剪。水文形状依据未叠加机场的自然生态生成，不用扩大机场周边干地来消除河道；遇水以桥接通。
- 夜间保留已确认的场坪、停车和燃油区射灯覆盖与强度；顺序进近灯只在当前进近端按2Hz由远到近运行，其他边灯保持常亮。详细灯光规则见 [AirportLighting](AirportLighting.md)。

## 运行流程

- 机场仍是City的低频Airport子类，普通biome选择器不单列。按世界坐标大约20–30个普通地形生成段出现一次；使用同一小机场，12/30两个进场端轮换。
- 机场之外沿用130米绝对巡航高度与原速度；机场进近240米，跑道入口约24米高，在入口后50米接地。
- 最后进近平缓提至约8.16m/s；接地保持速度，大幅制动在地面滑跑阶段发生，再降至约3.1m/s滑行。仅改变机场阶段的节奏。
- 接地后约140米滑跑到共用出口，沿连续圆弧驶入机坪，完成对正；拖车从停车位实际驶来，对接稳定0.8秒后，才以约1.1m/s倒库33米。
- 维护900秒；加油车、工具车沿实际曲线路线驶近，油管在到达后连接。离库前等待设备沿路线退回停车位。
- 沿同一固定路网出库；跑道等待10秒；150米加速滑跑（有效跑道余量190米），然后350米爬升，平缓恢复130米与原巡航速度。
- 飞机使用跨段连续切向与有限角速度，视觉姿态带轻微下滑、拉平和离地抬头。入库后屋顶约2.5秒内渐隐至90%透明，整段机身出门后恢复，让固定相机从两个机场朝向都看得到飞机。

## 时钟、存档与云

- 飞机与三辆地勤车由同一120Hz模拟推进；正常播放、暂停、测试16倍速均共用该逻辑。渲染只显示模拟状态，不在LateUpdate重复移动车辆。
- 保存飞机阶段/位移/速度、固定步余量、车辆坐标/航向/速度/路线、对接进度。恢复后连续运行；维护等待保留。
- routeVersion为6；旧大型机场地面访问恢复到新维修位，保留已等待时间。旧进近在新进近起点重新适配，保持保存高度范围。
- 普通云仍随实际飞机运动速度及微风变化；停机只保留微风。加载专用云规则不变。
