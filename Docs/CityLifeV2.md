# 城市交通、公园与高架规划更新 · 2026-10-04

已接入正式项目脚本；Main、飞机高度、摄像机、云层及原建筑窗户随机逻辑保持原有设置。旧版快照：`Checkpoints/CityLifeV2`。预览入口：`Art/Reviews/CityLife/index.html`。

## 高架与性能

- 第一层保持原有道路保留区规则。第二层为 18 米，允许跨越最多 3 层、实际屋顶不超过 13.5 米的建筑；另检查桥底到屋顶至少 2.5 米。实际高度与层数同时判定，不能仅靠类别名放行。
- 第二层先尝试长 S 弯，再试不同位置的较短完整 S 弯、横向 S 弯，最后才选长直线。半径为 24 / 36 / 48 米，圆弧按 15° 分段。最短完整路线 512 米，禁止生成短孤立残段。坡道从地面平滑接入。
- 建筑先规划，高架只检查和避让，不删除建筑、不把弯道周围改成绿地。楼房占地扩大 1 米作为立柱禁区。
- 将逐候选全区域人口构建改成先做地形和层间冲突检查，再按需要请求沿途人口；建筑碰撞使用 16 米空间索引。人口缓存用区域坐标键，避免地理缓存重建后反复失效。增加合理缓存容量、缓存资产占地，跳过不可能到达当前地图块的规划和网格工作。
- 地形、水岸、坡道净空、中高层建筑及既有高架冲突仍会否决路线。因此不是每个城市都保证有高架；种子 2409 本次可见区域无合格路线，种子 1068227040 出现两层路线，包括 848.8 米的第二层弯道。独立三种子规划检查共找到 3 条第二层路线，长度约 545–849 米，跨越 12 个低层建筑占地，支柱未落入建筑。

## 车辆

- 总池 96 辆（原 48）；最多 32 辆分配到高架，两层均支持。不是每屏保证 96 辆。道路不足时不强行生成。
- 高架车辆沿真实路线和坡度移动，按行进方向左偏车道；不直接在楼顶或空中生成导航格。
- 刹车前探距离 8 米，加速 1.2 米/秒²、减速 2.8 米/秒²；近车渐进减速。转弯速度为原来一半，转向角速度 140°/秒。
- 新加载高架有空额时，仅重分配屏外地面车辆，不在视野内删除车辆。
- 外观、色板及 50/30/20 配色概率不变，前白后红灯随昼夜原色发光。仍是轻量装饰交通，不是完整信号灯/交通仿真。

## 公园

- ENV-PARK-001 编号保留，改为地块适配的程序化公园；旧固定预制体留档但退出随机投放。
- 必须位于城市/镇区、由真实灰色道路四边围合的地块。浅绿与深绿都可；至少 64 平方米绿地且达到地块面积 55%。符合条件后 55% 尝试生成。
- 主径约 1.25–2.25 米，支径 0.9 米，支径间距约 16–24 米；限制路径覆盖率与家具密度。按面积最多 2–12 件长椅/灯具，间隔约 12–16 米。
- 只清理步道及家具附近树木。灯具夜间暖色发光，不使用额外实时灯、不参与建筑窗户随机熄灯。
- 几何按地图块和材质合并，没有每条步道、每张椅子的独立 Update。

## 验证与边界

限时独立 Unity Main 运行检查：两个种子、各 60 秒昼夜/大雨切换。96 辆车辆、公园生成、地图完整性通过；有高架的种子测到 32 辆高架车辆，并检查双向左行及支柱避楼。四向旧资产和资产 ID 没有重建，资产目录 63 项链接及编号检查通过。

同种子 2409 的初始同步地图生成从旧报告 48,694 毫秒降至约 6,216 毫秒，减少约 87%。Play 启动从约 51 秒降至约 9 秒。属于当前机器、编辑器批处理及缓存条件下的对比，不是独立 Player FPS 保证。

复杂高架种子初始地图约 11.47 秒，车辆 CPU 中位数 0.540 毫秒、P95 0.667 毫秒。两个样本的地图准备最大单步分别约 147 / 79 毫秒；2409 仍有 3 次应急完成，车辆更新含路网登记最大 101 毫秒，整帧最大约 724 毫秒。因此不能声称全部卡顿已消除。下一重点应是地图准备和道路登记进一步拆帧、阴影 Renderer 数量及 Player GPU 实测，不应牺牲既有观感盲目缩小可见范围。
