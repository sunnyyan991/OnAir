# 连续世界 V01（2026-09-10）

**当前地图生成版本为 [V05：连续岸带、斜向交通与群系预览](WorldV05.md)**。下方 V01/V02 链接保留为历史记录。

**当前已升级为 [V02](WorldV02.md)**：河道采用长直线与 45° 转折、取消盘旋、身后保留至少一分钟飞行距离、修正远景阴影与环境补光。以下为 V01 架构与历史验证记录。

## 产品方向

以用户提供的《西奥小镇》远景截图为构图、城市尺度与丰富程度的参考，沿用已有 3D 飞机与建筑。先验证世界组织，再做建筑和基础设施细节，最后验证像素呈现。像素化需要同时处理投影、轮廓、色彩、光照及运动稳定性，不能仅用后处理保证参考图效果。

## 已实现

世界坐标 → 连续自然地理 → 城区用途 → 不等尺寸街区与道路 → 建筑占地 → 分段加载。

- `ContinuousWorldPlan` 根据世界种子和全局坐标定义弯曲河道、远侧海岸、岸边绿带、公园与林地。相邻加载段查询相同地理，不独立抽选 City/Desert。
- 128×128 的规划区域用于确定性计算，内部递归不等比例切分，包含不同宽度道路与大小街区。规划区域仍是规则计算网格，尚未完全消除主干路重复节奏；不是把画面均分成同尺寸建筑地块。
- 住宅、混合、商业用途由连续空间场决定，相邻区域有相关性。沿用十三栋日式独立建筑和 CSV 分类倍率，住宅同类邻接增强，同款连续抑制。
- 街区内按建筑真实模块占地紧排，大街区保留内部通道；后排填补前排剩余进深。建筑不能放入水体、岸带、公园或林地。没有将用户的 10×10、100×50 示例写成唯一允许尺寸。
- `max_per_chunk` 在新模式中限制每个 128×128 全局规划区域内对应模型数量，和加载段解耦。商场、20 层塔楼各最多一栋；既有低空飞行通道保持高楼避让。
- 主横路在河流处形成简单桥面；桥面有边线。森林道路暂时中止，不生成任意贯穿自然地形的道路。
- 完整建筑按中心归属一个加载段，允许轮廓跨段，不切断建筑。跨段原点移动仍由原有航程系统驱动，昼夜和天气不重建地形。
- 同时加载 8 个 64 长度的切片，横向覆盖 384 场景单位；切片只是加载容器。默认相机正交范围从 40 调为 68，并将镜头后退，维持原投影角度。
- Main 默认启用 `JourneyController.continuousWorld`。路线保持 City 的光照与天气配置，地貌由连续规划决定。原 TERRAIN 按钮在新模式显示 EXPLORE / NEXT AREA，跳到前方区域。

## 文件与调参

- 世界形状、用途连续场、街区切分：`Assets/Scripts/World/ContinuousWorldPlan.cs`。
- 表面生成、模块放置、树木与桥面：`Assets/Scripts/World/ContinuousWorldLayout.cs`。
- 加载生命周期：`TerrainStreamer`；旅程分段及新模式开关：`JourneyController`。
- Main 的运行接入和远景镜头：`GameEntry`，没有添加另一个正式场景。
- 建筑基础权重与用途倍率仍在 buildings.csv。自然地形参数当前是代码中的首版参数，尚未做可视化配置编辑器。
- 旧 DenseCityLayout 和旧地形资源保留供对比；关闭 continuousWorld 可回到旧路线。旧验证工具面向旧模式，新模式用 `ContinuousWorldValidation.Run`，只能在批处理编辑器执行，会退出该实例。

## 验证

Unity 编译与 Main 运行通过。当前种子加载范围内 1,882 栋建筑，259 种不同街区尺寸；检查全体占地之间及跨加载段无重叠、建筑没有落入自然地类、昼夜保留实例、跨段保留 7 个已有切片。16 个种子的规划重复性检查通过；没有宣称完成 16 个种子的全部渲染验证。

实际预览在根目录 `Art/Reviews/ContinuousWorld`：overview.png、small.png（640×480）、dusk.png、next-area.png，以及 validation.txt。均来自正式 Main 的新模式，不使用临时 City-only 路线替换。Art 目录被 Git 忽略，向协作者交付需另附截图。

## 已知边界与下一步

这是连续沿航线世界的首版，横向仍有固定加载宽度，尚不是任意方向漫游的无限二维世界。生成当前同步完成，尚未做帧率基准、异步生成或远景 LOD，建筑更多后的切片生成卡顿需要专门测量。

自然地理是连续函数与噪声规则，不是真实水文模拟；河流暂未形成完整源流与入海网络。岸线以 2 单位网格采样，仍有阶梯；森林树种单一。桥面没有完整桥墩、护栏模型。部分道路会在自然区域边缘结束，还未做完整路网连通性求解。

建筑主朝向仍以两向为主，地块内部通道较规则，背排暂未应用同等丰富的邻接规则。下一轮优先看城市/自然占比、河道尺度、街区大小和镜头距离，再完善沿岸道路、道路连通、方向与地标，之后扩充材质和像素表现。
