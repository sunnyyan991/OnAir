# 云影投影与状态连续性

## 当前实现：2026-10-04

云影已从画面完成后的乘色覆盖，改成太阳方向的独立透明度投影图。云朵的真实水平几何、图集轮廓、位置和太阳方向共同决定投影；地面、建筑的重建表面位置、车辆和飞机按世界坐标接收阴影。

- 三层云分别写入投影图 RGB 通道，接收点高于该层时不受该层遮挡。每层微小的排序高度差以该层最高片面作为接收上限；当前建筑及飞机与各层间距大于这项差值。
- 标准强度为主光 shadowStrength 的 80%，表示直射光遮挡率，不是将最终画面亮度乘 0.2。环境光、窗户和招牌自发光保留。
- 与飞机/建筑主光阴影取较强遮挡，不重复乘黑；重叠云片取最大覆盖，不叠成漆黑。
- 原有 30 秒渐显/渐隐、提前生成、退出不占活动名额、密度、速度、第三层配额全部保留。全生命周期使用同一条投影路径，不在 fade=1 切换方式。
- 1024² 半浮点投影图保存连续透明度；不使用像素抖动、不把云作为全不透明主阴影投射器。独立图必要性：普通深度阴影图不能直接保存连续透明度。
- 地面等 Lit 材质使用 OnAir/Cloud Receiving Lit（基于工程现有 URP 14 Lit 前向着色，只扩展主光遮挡）；烘焙建筑和飞机在自己的着色器里读取同一张图。新增运行材质须用此接收 Shader；保留原材质 GUID、颜色和属性。
- CloudShadowOverlay 类名及文件名为旧兼容名称，已不绘制屏幕乘色滤镜。

## 本次定向验证

隔离小场景验证 0 / 0.5 / 0.999 / 1 透明度，采样亮度依次约 0.564 / 0.455 / 0.301 / 0.301；满强度切换无阶跃。检查主光阴影系数 0.8，Shader 编译及 Main 短时接入通过。亮度本身不是线性数值，因为截图经历色彩编码。

记录和画面位于 Art/Reviews/CloudTemple。没有运行全城市多种子长航程检查，不将短时检查表述为长期性能验证。

## 历史

2026-10-03 为修复实时深度阴影与渐隐乘色之间的跳变，曾统一成屏幕乘色覆盖；当时保证连续性，但不能正确只遮挡直射光。该方案现已替换。
