# 建筑配色标准

用户要求：灰色可以是城市中占比最大的单一色系，但不能全城灰色。使用日本实际建筑材料中常见的中性色与低饱和色，避免整体滤镜制造色彩变化。

## 后续资产规则

- 中性灰、暖白、米白、米色构成主要基底；按建筑类型与街区组合，不把每栋都涂成灰白。
- 木棕、砂色、陶砖色形成材料差异；灰绿、蓝灰、浅陶土/灰粉用于部分住宅或局部饰面，保持克制。
- 低饱和不等于无色：在正常日光下能辨识色相，在缩小到游戏尺寸后仍保留色块区别。
- 外墙、屋顶、门窗和木饰面分别设计；不对整栋随机染色，也不靠全局偏黄光照补救。
- 日夜和天气只影响合理光照，不能把所有素材的固有色重新压成同一种蓝灰。
- 制作时检查材质重绘规则是否把屋顶/木材统一替换为固定色；按确认的材质配色保留区别。
- 像素密度继续为4 PPU。概念图的细小纹理和栏杆在实现时整合为可读色块，不提高单栋密度。

灰色占比较高是本项目的美术选择，并非已经取得日本建筑颜色的统计比例。暂不在程序中设硬性颜色百分比，先看各批资产与街区合成效果。
