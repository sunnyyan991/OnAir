# 云层高度与第三层小云（2026-10-03）

## 2026-10-11：机场减速与停机时的云速

普通三层云原先始终按固定航线以 4.5/5.75m/s 屏幕基速移动，未使用飞机的实际速度，因此飞机停止后云仍如巡航时快速掠过。现在屏幕相对运动由实际飞机速度的投影加独立微风组成：正常巡航严格保留原速，减速时连续降低；停机时只保留原速 8%，结合既有个体倍率约为 0.32–0.51m/s。转弯、倒库和下降也使用实际运动方向；测试加速时跟随实际相机运动。

入场位置计算仍使用归一化方向，渐显距离和退场预测使用实际相对速度。30 秒渐显/渐隐、云层高度、天气配额和第三层固定名额均保留。第四/第五加载层继续使用独立的原有两倍基速和个体差速。

验证：相对速度计算检查确认巡航保持原速、逐级减速后连续下降、停机保留 8% 微风；Main 完整机场循环中实测一朵停机云的屏幕飘移为 0.46m/s。记录在 `Art/Reviews/Airport/Operations/main-validation.txt`。未扩展为长期天气/云层性能测试。

## 2026-10-08：标题菜单启动后的飞机高度修复

GameEntry 在菜单隐藏飞机前显式安装 AircraftHeightPreview。此前 AfterSceneLoad 的活动对象查找会漏掉被标题菜单隐藏的 FlightView，导致飞机视觉模型留在 65m 相机锚点，云层仍按原高度运行。

保持飞机视觉模型绝对高度 130m、相机锚点 65m；三层云名义高度分别为 97m、124m、140m。前两层保留微小排序偏移，第三层固定为飞机上方 10m。菜单再次隐藏飞机时组件恢复原局部位置，重新进入飞行后继续应用固定高度。

本次检查：初始化顺序、菜单启停路径、高度公式和 Git 差异检查通过；尚未在 Unity Editor 中执行 Play 验证。

按用户要求，原有低、中两层只抬高50米；新增飞机上方10米的小云层。

|层|原名义高度|新名义高度|形态与配额|
|---|---|---|---|
|原低层|47m|97m|L01–L06，原有单体与组合云海规则|
|原中层|74m|124m|M01–M06，原有天气配额|
|新增第三层|—|140m|仅M01、M04、M05、M06；固定2朵活动云|

飞机视觉模型固定在130米，FlightController根节点为65米相机锚点。旧两层继续使用原锚点公式并加50米，保留已有微小层内排序偏移。第三层使用AircraftHeightPreview.AbsoluteHeight＋10米，不能误用相机锚点。第三层的单片云统一在140米平面，不增加组合片。

第三层沿用中层小云5.75m/s基速与0.9–1.1个体倍率，以及现有上游入场、提前30秒渐显、锚点前完成渐显、退场30秒连续渐隐和影子透明度。预备/退场副本仍不占活动名额。启动初始铺云与原逻辑一致。

第三层有独立抽选随机序列和独立名额，不被多云、下雨或暴雨增加/减少，也不挤占前两层。天气仍可影响颜色与原有雷光效果。四个运行组为T3-M01、T3-M04、T3-M05、T3-M06，重用既有图集形状，未新增资产编号。云组候选池12→16，基础形态仍为12款。

验证：在独立工程Main Play中，将修改前源代码作为临时对照组件，按同一种子与天气序列模拟25分钟。前12组的身份、活动/到场/预备状态、轮次、透明度、屏幕轨迹与旧版逐步一致，根节点高度逐组恰好增加50米。新增层各天气下始终2朵活动云，形状仅指定四款，高度140米，渐显预备及渐隐退出均被覆盖；粒度保持。
