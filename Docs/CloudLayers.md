# 云层高度与第三层小云（2026-10-03）

按用户要求，原有低、中两层只抬高50米；新增飞机上方10米的小云层。

|层|原名义高度|新名义高度|形态与配额|
|---|---|---|---|
|原低层|47m|97m|L01–L06，原有单体与组合云海规则|
|原中层|74m|124m|M01–M06，原有天气配额|
|新增第三层|—|140m|仅M01、M04、M05、M06；固定2朵活动云|

飞机视觉模型固定在130米，FlightController根节点为65米相机锚点。旧两层继续使用原锚点公式并加50米，保留已有微小层内排序偏移。第三层使用AircraftHeightPreview.AbsoluteHeight＋10米，不能误用相机锚点。第三层的单片云统一在140米平面，不增加组合片。

第三层沿用中层小云5.75m/s基速与0.9–1.1个体倍率，以及现有上游入场、提前30秒渐显、锚点前完成渐显、退场30秒连续渐隐和影子透明度。预备/退场副本仍不占活动名额。启动初始铺云与原逻辑一致。

第三层有独立抽选随机序列和独立名额，不被多云、下雨或暴雨增加/减少，也不挤占前两层。天气仍可影响颜色与原有雷光效果。四个运行组为T3-M01、T3-M04、T3-M05、T3-M06，重用既有图集形状，未新增资产编号。云组候选池12→16，基础形态仍为12款。

|天气|原两层活动目标|第三层|总目标|
|---|---|---|---|
|晴朗|2|2|4|
|多云|5|2|7|
|雨|7|2|9|
|大雨|9|2|11|

天气切换继续沿用旧层平滑退出过程；表中为稳定后活动数，屏幕可见数量还受入场/离场位置影响。

验证：在独立工程Main Play中，将修改前源代码作为临时对照组件，按同一种子与天气序列模拟25分钟。前12组的身份、活动/到场/预备状态、轮次、透明度、屏幕轨迹与旧版逐步一致，根节点高度逐组恰好增加50米。新增层各天气下始终2朵活动云，形状仅指定四款，高度140米，渐显预备及渐隐退出均被覆盖；粒度保持。
