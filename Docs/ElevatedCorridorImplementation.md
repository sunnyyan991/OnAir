# 高架交通走廊：当前世界适配与实施

2026-10-03

当前世界不是一次性生成的有限地图，而是由固定种子确定、按相机需求加载的连续世界。高架路线必须先在共享世界计划中确定，再由各加载块按相同路线裁切生成。不能用“每张地图固定 0–2 条”管理无限世界，也不能让路线跟随飞机即时随机改变。

本轮落实到现有道路高架：

- 保留共享 512×768 区域归属与确定性缓存，保留受阻时至少 320 米的完整直线路线，拒绝短碎段。
- 常用圆弧半径为 24、36、48 世界米；弧线按 15°整数步进采样，弧与直线的连接保持切向连续。路线方向与半径由种子确定。
- 全路线统一计算里程与桥面接缝法线。桥面、护栏和隔音屏共用边缘，取代每段独立矩形与转角圆盘拼接。
- 双向桥面宽 5.8 米；预留 8 米建筑避让范围，并生成 6.2 米地面交通走廊，避免直接挤压窄街。立柱横梁与路牌同步适配宽度。
- 桥墩按全路线每 20 米配置，不在每条圆弧折线重新开始计数；路牌按全路线 192 米节奏配置。
- 引坡长度 144 米，端部缓和过渡，最大纵坡约 4.56%，替代原 32 米引坡。两端方向沿路线切线接入。
- 保留每帧约 2 毫秒的增量生成让步与原视野分块加载边界。

铁路适配结论：可复用路线控制点、固定半径圆弧、里程、占用包络和共享区域计划。铁路应另设更大半径、更低纵坡、轨道/接触网、站台平直段、车站和列车调度。本轮不生成铁路。

## 第二高度道路高架（游戏测试已启用）

- 原低层道路高架保留：最高约6米、5.8米桥面、原有建筑避让与地面走廊均不改变。
- 新增第二层桥面最高18米，宽4.2米，作为较紧凑的城市高架适配现有窄主路。路牌、护栏、立柱横梁随桥面宽度调整。引坡通常280米，短横向路线按路线长度的45%设置引坡，最大纵坡小于9%；此坡度仅用于道路，不能直接沿用到未来铁路。
- 使用原有房屋抽选、占地和位置计划，再确定高架。跨越对象必须同时满足三层及以下、实际屋顶（含屋顶构件）不超过10.5米；桥面底与屋顶至少留2.5米净空。中高层资产和不满足净空的路线整段拒绝，不移动或删除建筑。
- 高架主段沿128米共享主路。优先尝试向相邻主路转换的两处弯道，允许转换段跨过低楼；无合适弯道时才尝试直线。转弯半径24米，沿用15°弧段采样；不引入自由曲线。
- 第二层不参与 `ContinuousWorldPlan.Dry/Buildable` 的建筑预留，也不铺设贯穿街区的额外地面公路。因此不会为高架清空弯道两侧房屋或制造额外绿地。每20米检查桥墩位置，建筑占地外扩1米以内跳过整组立柱；横梁仍须满足屋顶净空。
- 第二层使用独立512×768米归属及共享缓存，X方向归属偏移256米，使弯道有机会出现在+Z航线附近。邻近路线由加载块统一裁切，范围覆盖128米的道路转换，避免跨块漏画。规划只预先计算房屋位置，不扩大地形加载范围、不实例化视野外建筑。
- 同时检查与原低层高架的交叉净空。地形、河流、飞机高度、相机和原低层路线选择规则保持原样。
- `WorldUpperHighways.Enabled=true` 为本轮测试开关；如需撤回第二层，改为false并重新进入Play。其余原有生成规则不需要回滚。

验证与截图：`Art/Reviews/UpperHighways/`。固定种子12345、169034996、1068227040共9个归属区域的审查生成6条第二层路线，累计12处低楼包络跨越。实际Main场景短时Play生成4个有第二层路线的归属区域，438栋活动建筑、可见地块缺失0、检查期间新增紧急补块0。保存实际街区图 `upper-generated-day.png` 和游戏飞机视图 `main-flight-day.png`。这是几何与短时运行检查，不代表长时间性能测试；真实生成率仍随种子、城市长度、河流及中高楼布局变化，不强行在不适合的区域生成。

后续整网工程还包括：跨河桥与高架的统一节点、跨共享区域的高架主线连接、支柱路口避让、车站走廊与铁路冲突优先级。现有高架候选仍避开河流和既有桥区，本轮不把独立跨河桥误报为已经接入高架网络。

验收入口：`HighwayCorridorReview.Run` 检查固定半径、15°转角、坡度、三组种子的路线长度和云影着色器；`HighwayGameReview.Run` 使用正式 Main 场景捕获圆弧高架细节和城市全景。输出分别为工作区根目录 `highway-corridor-validation.txt` 与 `Art/Reviews/HighwayCorridors`。

云影：正常云使用原 ShadowCaster 与原主光源阴影，深度回到原系统；只对退场副本启用连续透明投影。退场强度根据建筑像素着色器的直接光/环境光比例估算，30 秒淡出不占活动名额。
