# 建筑附加装饰标准（预留，未开启随机生成）

建筑本体与装饰资源分开登记。装饰未来按 DEC-SIGN（招牌）、DEC-TOWER（屋顶塔/红白塔）、DEC-SCREEN（动态看板）、DEC-EQUIP（设备）等用途编号；小、中、大是尺寸等级属性，不使用制作批次编号，不允许直接缩放已烘焙像素图制造尺寸变体。

BuildingDecorationSlots 是无 Update 的安装区域元数据：稳定 slot.id、立面/屋顶、局部位置、向外法线、容纳包围尺寸、允许装饰类别、是否允许动画。它不创建装饰、修改本体或消耗逐帧算力。本次仅在便利店与诊所的明确招牌区域及屋顶空位设置安装区域，传统木造店没有塔楼或屏幕安装区；未来每款楼需要逐款设计，不按包围盒随机贴东西。

安装顺序：生成建筑本体 → 根据种子、运行ID及全局位置确定固定随机数 → 先决定建筑是否装饰 → 按用途、年代、街区、屋顶承重/结构和安装区域筛选 → 按概率取具体款式 → 验证包围尺寸、无遮挡和邻楼/道路干涉 → 计入组合占地与最高点。预算是每栋/每街区同时生效，不能每个挂点独立高概率叠加。设置明确“无装饰”概率，传统住宅不出现大型商业屏幕；大牌、红白塔为低频。

静态装饰采用与建筑相同4 PPU、四向颜色/法线/深度与空间坐标，保持图块的统一颗粒和连续移动。本体像素渲染保留三维源模型，挂件以源模型坐标挂载并独立烘焙，不按纸片边界判断遮挡。没有相容像素遮挡和投影前不开启自动挂件。

装饰如果增高或伸出本体必须提前加入组合尺寸和飞行净空预算，不能沿用只含本体的BuildingFootprint。飞行高度当前来自建筑资源上界，未来应纳入允许的最高装饰尺寸并保守预留，不等飞到塔前才纠正。遮挡标识、窗户、阳台、逃生外廊、排水和楼梯一律作为禁放区域。

动态屏幕未来采用共享图集/动画材质，避免每栋一个实时RenderTexture或摄像机；可见实例才更新，远景低频或静态帧，离屏停更。白天/夜晚控制亮度，随机相位和内容基于实例种子。天气或时间切换不得重抽装饰和重建地图。若未来允许动态广告内容，建立内容资源引用而非改变建筑编号。

资产目录增加挂点/支持装饰字段与装饰类别独立台账；目录内装饰接入状态保持“预留”直到完整遮挡、阴影、组合占地、安全高度和性能验证通过。当前没有新增装饰生成概率或效果。
